# Robert N

I build practical software and data tools around operations, automation, analytics, and AI.

My background is in warehouse operations and stock administration. Most of my projects start with a real process or data problem and focus on replacing manual, fragmented work with clearer data, automation, and usable software.

## Current work

- **WareSight** — a warehouse intelligence platform for stock visualization, process analytics, KPI analysis, and operational performance tracking.
- **CHRONA** — a privacy-first personal analytics platform designed to bring long-term personal data into one contextual view.
- **Label Printing Tool** — an offline-first Windows application for designing and printing Zebra labels, with ZPL/PDF output, structured imports, local history, and database-backed workflows.
- **AI Context** — a system for maintaining durable AI project context, generating recurring summaries, and archiving useful information over time.

Some active repositories are private while they are still in development.

## How I work

- Start from the actual process and source data.
- Trace calculations and assumptions back to evidence.
- Automate repetitive work where it provides a clear benefit.
- Build tools around the people who will actually use them.
- Prefer local and offline-first designs when privacy or reliability requires it.
- Keep projects documented so decisions and implementation history remain understandable.
