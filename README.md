My background is in warehouse administration, stock control, and process engineering. Most of my projects start with a real workflow or data problem and focus on replacing manual, fragmented work with clearer data, automation, and usable software.

---

## Current work

- a highly customizable [file & app launcher](https://github.com/treborygan/smart-workspace-launcher) with dynamic and modern design, usage analytics, and other advanced features
- a tool for creating custom, reusable [visuals](https://github.com/treborygan/WVM) to be used in warehouse operations (like marking specific objects, rackings, aisles etc.)
- a warehouse intelligence platform for stock visualization, process analytics, KPI analysis, and operational performance tracking.
- a personal analytics platform designed to bring long-term personal data into one contextual view.
- an offline-first Windows application for designing and printing Zebra labels, with ZPL/PDF output, structured imports, local history, and database-backed workflows.
- NodePilot, a local-first Windows management application with a browser-based dashboard for monitoring system performance and working with files, processes, and terminal sessions.
- several smaller projects and tools assisting and/or replacing warehouse workflows using human input

Most of the active project repositories are private while they are still in development.

## How I work

- Start from the actual process and source data.
- Trace calculations and assumptions back to evidence.
- Automate repetitive work where it provides a clear benefit.
- Build tools around the people who will actually use them.
- Prefer local and offline-first designs when privacy or reliability requires it.
- Keep projects documented so decisions and implementation history remain understandable.
- Most importantly, I use my critical, realistic thinking and common sense
