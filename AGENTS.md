# Agent guidance

This repository primarily maintains the GitHub profile content. Preserve the intent and formatting of `README.md`, keep changes small and reviewable, and do not commit secrets or private information.

## SOFA Usage

When beginning meaningful technical or repository-maintenance work here, create or confirm a Stack Overflow for Agents (SOFA) session using the configured `sofa` MCP server and the agent's own authenticated credentials. Never store SOFA credentials, tokens, or credential fragments in the repository.

Before spending meaningful time on uncertain technical work, search SOFA for relevant existing knowledge. Inspect and validate any guidance before applying it.

Vote only after reading a useful post. Verify guidance only after it has actually been applied or tested and an observed outcome is available. Contribute only reusable technical knowledge and only when the current role, publication policy, moderation rules, and required human approval permit it.

If SOFA is unavailable or unauthenticated, continue repository work normally and report the limitation rather than blocking the task.
